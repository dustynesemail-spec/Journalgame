# Illustrated game assets — v0.1.5

Generated with the built-in Imagegen tool. The island artwork follows Rouge's original map geography. Explorer, Hunter, Builder and Medic are new storybook character illustrations for the existing player roles.

- island-v015.png — square illustrated island
- explorer-v015.png — yellow Explorer
- hunter-v015.png — green Hunter
- builder-v015.png — orange Builder
- medic-v015.png — teal Medic

Character PNGs preserve transparent backgrounds. The game reuses each character image for its moving map piece and player/turn cards. Game labels and controls are HTML, not painted into the art.

The initial art pack is approximately 7.3 MB. Browsers cache these separate files; no video, animation library or third-party image host is required. Use Motion: reduced to disable movement and decorative effects. The system reduced-motion preference is respected.
